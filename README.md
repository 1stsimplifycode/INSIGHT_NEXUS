# Insight Nexus — Study Partner

A study-oriented web interface and learning-resource collection.

## Files
- `INSIGHT_NEXUS_YOUR_STUDY_PARTNER.HTML` — primary study-partner page
- `Learning_Dashboard.html` — learning dashboard
- `INSIGHT_NEXUS_YOUR_STUDY_PARTNER.txt` — related text content
- Images and topic materials covering Python, concurrency, web scraping, and other computing concepts

## Open locally
Clone or download the repository and open `INSIGHT_NEXUS_YOUR_STUDY_PARTNER.HTML` or `Learning_Dashboard.html` in a browser. External assets, if any, require connectivity.

## Purpose
An interface prototype that brings study content and technical learning resources into a browsable format.
